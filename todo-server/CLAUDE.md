TODO App — тестове завдання (Full-stack)

Простий застосунок для керування завданнями (TODO) з аутентифікацією.

Структура репозиторію
.
├── todo-server/ # бекенд (NestJS)
└── todo-client/ # фронтенд (Next.js)

Стек
Бекенд: NestJS (у завданні — Express.js; NestJS працює поверх Express)
ORM: Sequelize або інший ORM
База даних: PostgreSQL (або SQLite для спрощення)
Фронтенд: Next.js
Робота з API на фронті: React Query (TanStack Query) — буде плюсом
Аутентифікація: JWT

Функціональні вимоги
Аутентифікація — реєстрація та вхід через JWT.
CRUD для завдань з полями:
title — назва
description — опис
status — один із todo | in progress | done
Список завдань з можливістю фільтрації за статусом.
База даних — PostgreSQL (або SQLite).
Фронтенд — Next.js, робота з API через React Query.
Бекенд — Express.js + Sequelize (або інший ORM).
